    .. admonition:: technical
    
        When an XML file is opened within a web browser, XML entities are typically resolved. For example,
        :code:`&amp;` will be displayed as :code:`&`. Thus, the browser will not display well-formed XML.
        If you need to process the file as actual XML, it is thus recommended to download it (e.g., via
        *right-click* on the link, then *save as...*).
